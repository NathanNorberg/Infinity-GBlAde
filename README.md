# Infinity GBlAde

A Game Boy Advance duel game inspired by the first Infinity Blade, built with [Butano](https://github.com/GValiente/butano).

Milestone 1 (the combat prototype) is complete: one enemy, dodge, block, parry, openings, HP and a debug overlay. The design lives in `docs/`.

## Building

Requirements:

- devkitARM (devkitPro)
- Butano 21.7.1, checked out so that `../Butano/butano` (relative to this folder) is the Butano library folder. Change `LIBBUTANO` in the `Makefile` if yours lives elsewhere.
- `python3`

```bash
make -j8
```

This produces `infinity_gblade.gba`. The folder path must not contain spaces, since Butano's makefiles can't handle them.

## Controls

| Input | Action |
| --- | --- |
| D-pad | Dodge left/right, duck (down), hop (up) |
| A (hold) | Block |
| B + direction | Parry during an enemy wind-up; slash during an opening |
| Start | New duel after a win or loss |
| Select | Toggle the debug overlay (L/R switch enemy tier while it's shown) |

## Tuning and art

- Every timing window, damage value and enemy tier is in `include/tuning.h`.
- Placeholder art is generated by `python3 tools/make_placeholder_art.py`, which writes the BMPs in `graphics/`.

The 8x8 font in `graphics/` and `include/` comes from Butano's `common` folder (zlib license).
